# 8-Bit Smash 3D

Fire balls at an 8×8 wall of pixel-art emoji blocks; knock them all off the platform. Built on Physics3D + three.js for play.nitzan.games.

## Run locally

```bash
./dev-server.sh
```

Open http://localhost:8080.

## Test

```bash
npm test
```
